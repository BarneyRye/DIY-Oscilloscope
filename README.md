# DIY Osciliscope
Design based on a **STM32F405RGT6**, with 2 options to connect up to 2 seperate leads. <br>
Used a 240x320 TFT ILI9341 screen module over SPI. <br>
[Example Screen: 2.8-inch SPI LCD Module 240 * 320 TFT Module ILI9341](https://www.amazon.co.uk/DIGISHUO-2-8-inch-ILI9341-occupies-Display/dp/B0DPZ3B171?source=ps-sl-shoppingads-lpcontext&ref_=fplfs&psc=1&smid=A3GCGSGY68R0P6&utm_source=chatgpt.com) <br>
Max inputs of +/- 20V, 40Vpp. <br>
USB-C connection for power or streaming waveform to seprate device.
